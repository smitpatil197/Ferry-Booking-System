# 🚢 Ferry Booking System

A responsive web-based Ferry Booking System designed to provide users with a simple and convenient way to explore ferry services, enter passenger details, make bookings, and complete a simulated payment process.

## 📌 About the Project

The Ferry Booking System is a college web development project focused on creating a user-friendly online ferry booking experience.

The website includes ferry booking, user login/signup interfaces, booking confirmation, payment simulation, reviews, and a gallery section.

## ✨ Features

- 🏠 Responsive home page
- 🚢 Ferry booking interface
- 👤 User login and signup pages
- 📅 Travel date and passenger selection
- 🎫 Booking confirmation
- 💳 Simulated payment interface
- 🧾 Booking summary
- 🖼️ Gallery section
- ⭐ Reviews section
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
